# Jelly

A collection of single-file interactive browser studies. Each one lives in its own folder with its own `index.html`.

| Folder | What it is |
|:---|:---|
| [melon-jelly-knife](melon-jelly-knife/) | WebGPU soft-body watermelon slice you can stretch and cut with a knife |

## Run locally

WebGPU needs HTTPS or localhost, so serve the repo root:

```bash
python -m http.server 8765
```

Then open http://localhost:8765.
